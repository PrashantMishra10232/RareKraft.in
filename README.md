# **Rare Craft**

**An eCommerce platform built using the MERN stack (MongoDB, Express.js, React, Node.js). This project is designed to serve as a fully functional online store with features for browsing products, managing user accounts, and handling orders.**

## **Features**

**1. 🔒 User Authentication: Secure login and signup using JWT.**
**2. 🛒 Product Management: Add, edit, or delete products (Admin-only feature).**
**3. 🛍️ Shopping Cart: Add products, manage quantities, and remove items.**
**4. 📦 Order Management: Place orders and view order history.**
**5. 💳 Payment Integration: Support for [Stripe/PayPal].**
**6. 📱 Responsive Design: Fully optimized for both desktop and mobile devices.**

## **Tech Stack**

### Frontend:

**- React.js: For building an interactive and dynamic user interface.**
**- Redux (or Context API): For state management (if used).**
**- CSS / TailwindCSS: For styling.**

### Backend:

**- Node.js: Server-side JavaScript runtime.**
**- Express.js: Web framework for creating APIs.**

### Database:

**- MongoDB: NoSQL database for storing user, product, and order data.**
